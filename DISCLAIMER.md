## Project-specific technical risks

- The installation modifies your Mac's partition layout and boot firmware.
  A failure during the process can leave the machine unable to boot macOS
  normally.
- There is no automatic uninstaller in the current version.
- Always create and verify a full backup before running any of the scripts
  in this repository.
